# Block Build

Block Build is a 2D multiplayer blockchain-based game where players:
- Buy land using ERC-20 tokens
- Own land and buildings as NFTs
- Hire other players to work
- Earn and spend tokens in a player-driven economy

## Tech Stack
- Phaser 3 (Frontend)
- Node.js + Express (Backend)
- Socket.IO (Real-time multiplayer)
- Hardhat (Smart contracts)
- Ethereum (ERC-20 & ERC-721)

## Project Structure
client/ - Phaser game  
server/ - Backend server  
contracts/ - Smart contracts
